# External DX11 Overlay for Nexus
Wrapper for [External DX11 Overlay](https://github.com/SorryQuick/external-dx11-overlay) able to be loaded and injected with [Raidcore Nexus](https://raidcore.gg/Nexus). Derived from Olivier Fortier's ("0l1b0t") [fork](https://github.com/OlivierFortier/external-dx11-overlay/tree/nexus-integration-small).
